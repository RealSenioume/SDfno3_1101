# Figures for the report

Save the screenshots here with these exact names; `docs/08-report-draft.md`
already references them.

| File | What it must show | Where it appears |
| --- | --- | --- |
| `fig1-wheel.png` | The wheel open at the pointer, one slice highlighted, slice labels readable | §6.2, Figure 1 |
| `fig2-mark.png` | The mark left after release: expanding ring, dot and slice name over the desktop | §6.2, Figure 2 |
| `fig3-settings.png` | The settings window with all groups visible | §6.2, Figure 3 |

Capture guidance:

* Use Win + Shift + S, or `Print Screen`, and keep the crop tight around the
  wheel. Crop width around 600-800 px is enough; do not upscale.
* Capture at 100 % display scaling if possible, so the labels are sharp.
* For Figure 1, hold the drag still for two seconds before releasing so the
  gold highlight is fully animated (τ = 35 ms settles well within that).
* For Figure 2, screenshot within the 900 ms mark lifetime; increasing
  `mark_duration_ms` in Settings makes this easier.
* Do not include personal information (chat windows, account names) in the
  background.

Erase this file or keep it; it is not part of the report body.
